一、无法使用麦克风
CedarPitch 需要麦克风权限来检测吉他的实时音高。

请按照以下步骤检查：

打开 iPhone 或 iPad 的“设置”。
进入“隐私与安全性”。
点击“麦克风”。
确认已经允许 CedarPitch 使用麦克风。
重新打开 CedarPitch。
CedarPitch 只在设备内存中实时分析音高，不会把麦克风声音录制成文件，也不会上传麦克风音频。

二、无法识别琴弦或识别不准确
建议按照以下方式测试：

在相对安静的环境中调音。
每次只拨动一根琴弦。
拨弦后等待音高稳定。
避免其他琴弦同时振动。
将设备麦克风靠近吉他，但不要紧贴音孔。
检查保护壳是否遮挡麦克风。
可以切换到“手动选弦”，再点击琴头上对应的琴弦按钮。
如果第六弦低音 E 不容易识别，请先轻触其他琴弦停止共振，再单独拨动第六弦。

三、偏低、偏高分别是什么意思
“音偏低”：需要把琴弦稍微拧紧，提高音高。
“音偏高”：需要把琴弦稍微放松，降低音高。
“音准正确”或“OK，好了”：当前琴弦已经达到允许的音准范围。
调整琴弦时请缓慢旋转弦钮，避免琴弦突然断裂。

四、语音提示声音太小
请检查：

在 CedarPitch 的“设置”页面提高“播报音量”。
播放语音时使用设备音量键提高媒体音量。
检查声音是否被输出到蓝牙耳机、音箱或其他设备。
暂时断开蓝牙设备后再次试听。
点击“设置 → 语音提示 → 试听语音”进行测试。
所有语音提示都是随 App 安装的本地音频文件，不依赖网络。

Microphone access
CedarPitch requires microphone permission to detect guitar pitch.

Open:

Settings → Privacy & Security → Microphone → CedarPitch

Enable microphone access and reopen the app.

Microphone samples are analyzed in device memory for real-time pitch detection. CedarPitch does not record microphone audio to a file or upload it.

Pitch or string recognition problems
For better results:

Tune in a relatively quiet environment.
Pluck only one string at a time.
Mute the other strings to prevent sympathetic vibration.
Keep the device near the guitar without covering its microphone.
Try Manual String Selection and select the corresponding string button.
For the low E string, stop the other strings from vibrating before plucking string 6 again.

Voice prompt volume
Increase Voice Volume in CedarPitch Settings.
Use the device volume buttons while a prompt is playing.
Check whether audio is routed to Bluetooth headphones or speakers.
Disconnect Bluetooth temporarily and try Preview Voice again.
Voice prompts are bundled local audio files and do not require a network connection.
